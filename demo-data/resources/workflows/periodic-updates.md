# Periodic Updates Template

Use this template when the agent needs to post recurring status updates to the incident workspace or a status call.

## Cadence examples

- every 30 minutes during active containment
- every hour during investigation stabilization
- every 4 hours for lower-severity monitoring

## Update format

- what changed since the last update
- current blockers
- customer or business impact changes
- actions completed
- actions next up

## Prompt

Write a concise periodic incident update for analysts and stakeholders. Keep it skimmable, anchored in new facts since the last update, and call out whether the incident is improving, worsening, or unchanged.
